# Contribuindo

Obrigado pelo interesse no review-sparring! O projeto é pequeno e mantido por uma pessoa só, então o jeito de contribuir é simples: **abrir uma issue**.

## Quero uma stack nova

[Abra um pedido de stack](https://github.com/paulohm0/review-sparring/issues/new?template=stack-request.yml). O mantenedor cria a stack e avisa na própria issue. O passo a passo está em [docs/request-a-stack.md](docs/request-a-stack.md).

## Encontrei um problema ou tenho uma ideia

Abra uma issue descrevendo o que aconteceu ou o que você gostaria.

## Pull Requests

Os packs de stack são escritos pelo mantenedor, e não por Pull Request. Um pack é texto que o Claude segue como instrução em toda sessão de quem usar a stack, então ele é criado e revisado em um lugar só. Para qualquer outra mudança, abra uma issue antes de escrever código.
